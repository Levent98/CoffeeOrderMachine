# CoffeeOrderMachineQt

A Qt Widgets version of the Coffee Order Machine project.

## Improvements in this version

- Cleaner two-column desktop layout
- Styled cards for menu, drink details, and order summary
- Quantity selection with automatic total price calculation
- Read-only order summary panel
- Status indicator for the current order flow
- Improved reset behavior for demo purposes

## Build

Open the project in Qt Creator and use a Desktop Qt MinGW kit.


Updated layout notes:
- Larger default window size
- Scroll support for smaller screens
- Minimum heights added to avoid clipped buttons and text
